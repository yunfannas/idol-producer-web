# =LOVE Media-Model Simulation

Window: 2025-07-05 to 2026-01-04 (6 months from Scenario 6 start)

This is a media-layer projection, not a full concert/live simulation.

Assumptions:
- Start from Scenario 6 opening cash and =LOVE group stats.
- Keep the current daily finance model for digital sales, fan meetings, goods, staff, office, promotion, and monthly salaries.
- Remove the current flat passive media income and replace it with event-driven media income/fan growth.
- Add extra =LOVE-scale operating costs for administration and advertising every day.
- Add per-event travel, making, and advertising costs.
- CD-bonus meetings do not add separate ticket revenue; those customers are already counted inside CD sales.
- CD net revenue uses JPY 500 per sold copy.
- Each track on a released CD is assumed to carry JPY 1,000,000 of MV spending.
- Exclude true concerts/festivals/guest lives from this pass so the result isolates media economics.

## Read

- Under this first-pass media model, =LOVE stays profitable over the 6-month window even after heavier media-side operations costs.
- This pass should be treated as a media-balance probe. It does not yet include live-tour revenue/cost resolution from the official schedule, so it is intentionally conservative on big-event upside.
- The clean next step is to run the same script for iLiFE! and 高嶺のなでしこ, then tune the 3 biggest knobs only: event revenue base, fixed daily admin burden, and live-event merchandise/making cost.
