## Core comparison rule

For ordinary live-idol groups:

- **C**: Live is clearly stronger than the current Jams Collection C-tail benchmark, or the total Live/Music/Brand package clearly belongs above C-.
- **C-**: either (a) a valid current TIF Main/HOT floor applies, or (b) trailing-12-month own-live ticket gross / paid attendance / representative live scale is clearly stronger than NANIMONO.
- **D+**: if neither condition is demonstrated, keep at D+ even if there is one large venue, an O-EAST/Zepp peak, or strong scene recognition.

Ticket gross remains the primary Live benchmark; paid attendance and average/representative attendance are auxiliary. Low-price / trial / invitation inventory is not manually double-discounted if gross is already used, but it weakens venue-capacity evidence when actual ticket mix is unknown.

## Current anchors

- **NANIMONO = D+ head / C- gate comparator.** A non-TIF group must be clearly stronger, not merely comparable, to receive C-.
- **Jams Collection = C tail comparator.** A C- group that is clearly stronger than Jams in current Live should be reconsidered for C.
- **High-profile venue alone is not a tier.** O-EAST full, Toyosu PIT, Zepp, LINE CUBE, etc. require price mix / attendance / repeatability context.
- **TIF Main/HOT is a floor, not a promotion to C.** It locks C- when the slot is a valid independent group appearance.
