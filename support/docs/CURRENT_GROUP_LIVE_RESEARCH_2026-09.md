# Current Japanese Female Idol Live Research — 2026-09

Working current-market research matrix for the lower large-idol / C / C- / edge-D+ zone. This is **not** Scenario 6 data.

## Live method

Primary signal: **repeatable ticket gross**.
Secondary signal: **paid attendance / audience breadth**.
Then use repeatability, regional breadth and exceptional-event discounts.

Do not cap premium-ticket value. If ticket-class sales are estimated, estimate total gross from actual prices and expected allocation/sell-through. Premium/front tickets often sell out first, so a premium sell-out alone is weak evidence of whole-venue demand.

Reference gross bands (working, not hard cuts):

| Live | Repeatable ticket gross | Attendance cross-check |
|---|---:|---:|
| D+ | ¥2.5–4m | ~500–1,000 |
| C- | ¥4–7m | ~800–1,500 |
| C | ¥8–15m | ~1,500–2,500 |
| C+ | ¥15–30m | ~3,000–5,000 |
| B- | ¥30–50m | ~5,000–8,000 |
| B | ¥50–90m | ~7,000–12,000 |
| B+ | ¥90m+ repeatedly | 10,000+ |

If gross and attendance point to different tiers, gross sets the commercial ceiling but attendance limits fanbase-breadth interpretation. Example: ¥15m generated by 900 very-high-price buyers is not the same Live structure as ¥15m from 2,500 ordinary-ticket buyers.

For ordinary TIF/live-idol-route groups, no regular TIF Main/HOT Stage in either of the latest two years normally blocks C-, unless independent Live evidence or a different ecosystem clearly overrides the gate.
