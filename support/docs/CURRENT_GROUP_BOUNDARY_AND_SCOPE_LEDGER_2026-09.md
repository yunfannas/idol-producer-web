## Scope flags

- `ranked_current`: participates in the real-world current idol-group ranking when active.
- `scope_excluded_current_rank`: excluded from the real-world ranking by category, but still receives normal game tier ratings.
- `inactive_current`: no longer active on 2026-09-09; preserve historical/game ratings only.
- `STOP`: active at snapshot but officially announced end/disbandment; keep ranking if still active, show red STOP trend.

Voice-actor artist units such as `i☆Ris`, `TrySail`, `DIALOGUE+`, and `22/7` are `scope_excluded_current_rank` by user rule, while still receiving normal game tiers. Love Live!-type franchise-cast groups remain outside ordinary group scope entirely unless separately required by game content.
