概览

偶像制作人（Idol Producer）是一款经营模拟游戏，界面风格参考 Football Manager 的信息密度布局。 你在固定历史剧本中负责一支经营组合。游戏世界由真实偶像产业启发的组合、成员、歌曲与碟片数据构成。

主要压力来源：

  • 时间 — 日历按天推进。
  • 资金 — live、训练、人事与星探均需花费。
  • 阵容状态 — 成员有体力、士气与训练负荷。
  • 知名度 — 字母等级与粉丝规模决定可行的会场与 live 类型。

快速上手

  1. 打开游戏（index.html），等待数据库已就绪。
  2. 选择新游戏，输入制作人名称，从排序列表中挑选组合。
  3. 点击开始剧本 — 开局日期由剧本决定（例如剧本 6 为 2025-07-20）。
  4. 用左侧栏打开收件箱、日程、Lives、偶像等栏目。
  5. 准备好后，点击顶栏下一天模拟下一日历日。
浏览模式 — 在开始界面选择浏览，可在无存档的情况下查阅数据库（组合、偶像、歌曲）。 未开始或读取游戏前，下一天与财务功能不可用。
语言 — 游戏内可在开始界面切换英语与简体中文。 本手册为简体中文版；英文手册另附。

剧本

成立日期规则

目录中的成立日期取 documented 的最早一日： 首次公开宣布、解禁／披露活动，或出道 live，以最早者为准。

界面

布局为经典经营游戏结构：

  • 顶栏 — 标题、经营组合名（可点）、当前日期、现金（¥）、下一天、主页菜单（存读档／栏位）。
  • 左侧栏 — 栏目导航与偶像备选名单。
  • 主区域 — 当前栏目的表格、详情与表单。
  • 状态栏 — 当前视图名称与回合数。

主页旁的后退／前进（‹ ›）在当次会话的浏览历史中切换视图（类似应用内“返回”）。

核心循环

  1. 读收件箱 — 处理确认项、live 结果与剧本事件。
  2. 规划 — 查看日程、训练、财务与阵容状态。
  3. 执行 — 调整训练、查阅歌曲、星探，或在 Lives 中预订与编辑公演。
  4. 推进 — 按下一天运行当日模拟。

每推进一日，回合加一，current_date 前进。 自动系统可能预订例行 live、结算训练并记入账目，具体取决于存档状态与等级模板。

部分收件箱消息在做出选择前会阻止下一天，尤其是需要你决断的重要剧本事件。

主要栏目

栏目用途
收件箱通知、live 结果、剧本邮件；部分含选项，可能阻挡日推进。

日程月历与「自下一日起一周」概览已订公演与近期结果；可点击顶栏日期跳转。
Lives新建公演、编辑或取消待办场次、查看过往结果与音乐节出场。
歌曲经营组合曲目表（按人气排序）；用于歌单与制作流程。
制作录音／制作向界面（完成度因剧本与版本而异）。
发行发布与上架流程（剧本接入后可用）。

财务手头现金、月度开支、live 收入与等级预算模板。

备选名单

在偶像详情页可将成员加入侧栏备选名单，便于星探或训练时对照。 备选名单随存档保存；纯浏览模式下不可用。

字母等级（S–F）

每个组合有字母等级，从 S（商业规模最大）到 F（ livehouse 级）。 等级影响：

  • 开局资金与月度成本模板
  • 典型 live 频率（拼盘、单独、音乐节等）
  • 模拟中的粉丝规模下限
  • 新游戏选组合时的排序
等级典型规模（摘要）
S体育馆级巡演、大厂发片、全国电视
A具备体育馆能力，销量与媒体强
B大厅级；可能达成武道馆里程碑
C大厅巡演 + 密集拼盘
D较小会场，极度依赖拼盘
E小场地，多为拼盘
F livehouse，培育核心受众

上榜组合的 S–C 来自策划的 Idol Ranking 2025 映射； 其余组合仅能推断为 D–F。字母等级 S 与 live 类型 S（生日／纪念等特殊 overlay）不是同一概念。

Live 与日程

Live是主要对外活动。每场含live 类型、会场、日期，及可选歌单。 类型编号用于设计与财务：

类型名称说明
1大型演唱会长时段；大场地；庆功可另日举办
2巡回演唱会多城市巡演各站
3音乐节多日音乐节；每组约 30 分钟
4拼盘（対バン / Taiban）同晚多组；约 20–35 分钟；常有特典会
52／3／4 人联合联合 headline；合作环节
6单独 live（进阶）比常规单独更隆重；俱乐部～大厅规模
7例行 live livehouse 定期驻场
S特殊 overlay生日／周年等，叠加于 4、6 或 7

公演来源有两类：你手动预订，以及按组合字母等级的月度自动排期 （例行 live、拼盘、联合、单独、音乐节等）。月末可在收件箱的营运提示中确认是否自动填满下下月档期。

手动预订公演

打开 Lives，使用工作区标签：

标签用途
New Live新建：类型、标题、日期、会场、时段、彩排、票价、歌单、特典会、周边摊位。
Scheduled待办公演列表；点击行在 Live 中打开编辑。
Live修改当前选中的待办公演，或 Cancel Live 取消。
Past已演出场次与成绩、收入摘要。
Festival经营组合在音乐节 timetable 中的出场（如 TIF 会导入日程）。

New Live 流程：

  1. 选择类型（例行、演唱会、拼盘、音乐节）— 预设会调整默认时长与特典会时间。
  2. 设定日期、会场、开演／终了，以及可选彩排时段。
  3. 编辑歌单：从组合曲库添加曲目，插入 MC 或 break，拖拽排序。
  4. 可选开启特典会／拍立得与周边摊位及预期收入。
  5. 点击 Schedule Live — 场次出现在 日程 与 Scheduled 中。

日程页的月历会标出有公演的日期；即将到来的一周从下一模拟日开始。 按下一天结算当日公演，结果进入收件箱与 Past。

特典会（tokutenkai）

类型 4–7 常含特典会：购物或购票兑换谈话席、拍立得等。 默认设计约为 live 后约 60 分钟，谈话档 ¥2,000／¥3,000 混合。

财务

游玩时顶栏显示手头现金（¥）。开局预算取决于剧本编号与组合字母等级。常见支出：

  • 成员报酬（随等级缩放）
  • 月度管理与训练预算
  • live 制作与会场费用（按类型与会场等级）
  • 启用星探公司的服务费

收入来自票务、周边及活动规则。打开财务可查看账目与月度明细（视当前版本）。

偶像与训练

每位偶像有可见／隐藏属性（0–20）、生日、体力、士气，以及按组合划分的所属履历（加入／毕业日期）。

训练

为每位成员设置当周训练强度（歌唱、舞蹈、综艺等）。 训练消耗体力并影响士气；对状态差的成员过度训练可能导致倦怠。 可安排上午／下午场次，有每周负荷上限。

组合详情字段

  • 成立 — 最早宣布／解禁／出道日
  • 制作人 — 署名的制作人，如「前 Maneki Kecak 成员 Fukase Mio」
  • 事务所 — 经纪公司（若目录有记录）
  • 碟片 — 发行列表，曲目关联歌曲库

星探

星探公司（按城市与等级）通过三种渠道搜寻人才：

  • 自由身 — 当前无所属组合
  • 转籍 — 在其他组合活动但可能被挖角
  • 应征 — 独立偶像或未经事务所的应征者

公司收取服务费，并倾向推荐籍贯与公司地区匹配的偶像（东京、大阪、名古屋等）。等级越高，覆盖面越广。

资格规则

  • 当前有所属者不算自由身。
  • 引退（不进入推荐）：自上一段所属结束至今的年数 + 当前年龄 ≥ 30，视为引退，不再推荐星探。
  • 日后可能加入活跃 solo 名单，筛选仍在活动的自由身 solo。

收件箱

收件箱是运营信息流：live 提醒、演出摘要、财务备忘与剧本叙事。 部分消息含选项；若界面阻止下一天，须先做出选择。

未来日期的剧本事件（出道、毕业、成立里程碑等）在生效日由剧本运行时引擎应用。

存档与浏览

存档栏位

游戏保存在浏览器本地存储中，含编号栏位与自动存档。 使用主页 → 保存游戏／读取游戏，或在开始界面读取。 存档架构为版本 11，新游戏时会嵌入当时剧本数据库快照。

存档内容

  • 制作人名、经营组合、当前日期、回合、财务
  • 各偶像模拟状态（训练、体力、士气）
  • live 日程、收件箱、星探委托与剧本标记

浏览数据库

浏览模式只加载剧本 JSON、不创建存档，适合开档前查阅组合与歌曲。 无现金、无法推进日期、备选名单不保留。

提示

  • 连续点下一天前先清空收件箱，避免遗漏阻挡项。
  • 重要周前在 Lives → New Live 加订场次，并用 日程 核对是否与自动排期冲突。
  • 低等级组合靠拼盘数量生存；D–F 勿按体育馆经济规划。
  • 重要 live 周前注意体力偏低成员的训练负荷。
  • 不熟组合名时，在组合详情中打开 Wiki 链接了解背景。
  • 剧本 6 推荐开局组合是策划子集，非全部 400+ 组合数据库。
